# 31 万 star 的 Agent 技能框架<br>凭什么一年冲到榜首

前两天翻 GitHub 趋势榜，又看到那个名字。

obra/superpowers，31.2 万 star，2025 年 10 月才建仓，一年时间冲到技能类项目第一名。

不是工具，也不是插件。它做的事很朴素：**把一套软件开发方法论，写成 Agent 能照着执行的技能集。**

## 01 它到底是什么

作者管它叫「agentic skills framework」，翻成中文大概是「给 Agent 用的技能框架」。

里面装的不是代码库，是一整套流程：**先头脑风暴，再拆需求，然后分子 Agent 并行开发，最后回收结果做验证。**

每个环节都是一个 skill 文件，Agent 读完就知道这一步该干什么、产出什么、什么时候该停下来问人。

这解决了一个老问题：你用 AI 写代码，它经常一步到位地乱写；你让它先规划，它规划完又开始跑偏。

**有了流程约束，Agent 才像在按工序干活，而不是在猜你想要什么。**

## 02 装完有什么变化

最明显的三点。

第一，**它会先问你问题**。需求不清楚的时候不再直接开工，而是列几个选项让你选。

第二，**它会把活拆开**。一个大任务分成几个子任务，分给不同的子 Agent，最后合并。

第三，**它会自己检查**。写完跑测试，跑完看结果，不对就回头改，不用你一句句盯着。

代价也有：流程多了，简单任务会显得啰嗦。**小改动别用它，大项目才值得。**

地址：github.com/obra/superpowers

## 03 写在最后

这类项目的价值，不在于替你写多少代码，而在于**把「怎么做事」这件事本身沉淀下来**。

工具会过时，方法论不会。

如果你也在用 Claude Code、Codex 或者 Cursor，值得花半小时翻一遍它的 skill 目录——哪怕不装，看看高手怎么拆解一个开发流程，也够用了。
